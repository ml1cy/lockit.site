# lockit.site

A single-page reminder to lock your workstation with **Windows + L** (or **Control + Command + Q** on a Mac).

- Static, dependency-free `index.html`, so it can be deployed as-is (e.g. Cloudflare Pages).
- The keycaps animate on a loop and respond to your actual keyboard. Press Win/⌘ + L on the page to see a mock lock screen.
- Honours `prefers-reduced-motion`.
